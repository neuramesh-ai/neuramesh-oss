# Security

Report a vulnerability in private. Do not open a public issue for it.

1. Preferred: GitHub private vulnerability reporting. Open <https://github.com/neuramesh-ai/neuramesh-oss/security/advisories/new> and fill in the form.
2. Or send an email to <security@neuramesh.app>.

Include the app version, the steps to reproduce the problem, and the impact you expect. We answer as fast as we can. There is no service-level commitment. We tell you when we fix the problem and when we publish the fix.

There is no bug bounty program.

## In scope

The source in this repository, the desktop app, and the hosted service at neuramesh.app.

## Out of scope

Third-party services that NeuraMesh connects to. Report those to their owners.
