The thread tells you a file exists; it never shows you the file.

The fix rides three things that already exist: previewType() already classifies a file by name+kind+content, Md already rewrites #1032 into a real link, and .mkdoccard is already a bounded scrollable doc canvas. Point them at attached artifacts and the deliverable renders in the transcript, typed, small, and scrollable — while staying exactly as attached as it is now. Automatic by default (files on the message get cards, no agent action); an nmf fence when an agent wants to show a file mid-run or choose what gets a canvas.
