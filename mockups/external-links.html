The link choice: a click on a web link asks where to open it

Today every web link in neuramesh leaves the app. A markdown link in a message, the reply radar's Open post, an article's sources and View on X all call the OS browser, and a raw anchor opens a bare Electron window because the main window has no popup guard. The app already has a real browser tab in the side dock. This round puts one choice between the click and the browser: open the page here, or in the browser you use. The popover is the app's popover recipe. It grows out of the press, over nothing, and folds back.

Stop 1A click asks. The head says where the link goes, and two rows say where it opens.

The popover is the Popover primitive (ui/Popover.tsx, 264 wide), so it inherits the anchor recorded at the press, the frozen origin, the viewport clamp and the reduced-motion path. The head is the fact you decide on: the host in the app's mono, the path under it. The rows wear the one row-menu recipe. Row one wears the neuramesh mark: the app is the place, so its mark names the row. Row two wears the browser's own icon and name, as the OS reports them. Stop 3Keys, and the fast path for people who always want their browser.

The popover never charges more than one keystroke. And a link click with ⌘ held skips the choice and opens the OS browser at once, the same gesture that opens a new tab in every browser. That is the fast path for this round. A stored preference (always here, always there) is a Settings row for a later round, once the choice has been lived with.

  • ↵Open in neuramesh. The first row is highlighted when the popover opens.
  • ⌘↵Open in the default browser, from anywhere in the popover.
  • ↑↓Move the highlight. Tab cycles the same two rows.
  • EscFold it back into the link. A click away does the same.
  • ⌘ clickSkip the choice. The link opens in the OS browser with no popover. Middle click does the same.
  • right clickCopy Link stays where it is, on the native context menu.
Stop 4The second row is whatever the OS says the default browser is.

Electron asks the OS for the handler of https: (app.getApplicationInfoForProtocol): a name and an icon on macOS and Windows, a name on Linux. The renderer asks once per launch and keeps the answer. The icon is drawn at 16px with a 4px radius, in the icon column the row-menu recipe already has.

Stop 5Where the choice applies, and where it does not.
  • Every web link in the sheet. Markdown links in messages, plans and docs (Md.tsx), the article reader's sources, the reply radar's handle and Open post, View on X, the design studio's Open the project, the setup cards.
  • One seam, not one call site each. A capture-phase click listener at the root catches every <a href="http…"> the app renders, so a card that forgets to opt in is still covered. Components that open a page by code call openLink(url).
  • The floor is in main. The main window gets a window-open handler and a navigation guard: a stray popup or a same-window navigation to the web hands the URL to the OS browser and is denied, so a bare Electron window can never appear again.
  • Not intercepted: the browser pane's own ↗ button (already a browser), Connect and billing flows (they must land in the OS browser's own session), and the web client, which is already a browser and keeps a new tab.
  • Reduced motion: the popover fades, as every popover does.
