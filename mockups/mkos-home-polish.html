Marketing OS home polish

three production concerns · full-width bar · connectors on the home · Run for…

01The home, unscoped — bar at content width, connectors at a glance

The bar: a one-line CSS fix — the scope bar carried its own 18px side padding inside an already-padded column, so it always sat 36px short of the content. It goes to zero side padding and every destination (Routines, Whiteboards, Files) inherits the fix. Connectors: each project card grows a connector strip — the four publish networks + analytics as glyphs with live status dots (green = connected, amber = needs re-auth, dim = off). The strip is a glance, not a control: clicking the card still scopes to the project, where the full Connections section lives (scene 02).

03"pick a project" becomes Run for…

The old label was direction with no verb — the row was DISABLED until the human found the scope pill. Now the row works from every scope: in all-projects it carries a Run for… › pill, and clicking opens a picker of marketing-ready projects with this playbook's own state per room — pick one and the ask drafts exactly as a scoped run. One ready room in the workspace? No picker — the click just runs. A not-set-up room shows dimmed with the reason, never hidden.
