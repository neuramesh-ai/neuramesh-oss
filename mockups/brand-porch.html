C2 · The caught-up peek

Home’s needs-you list runs empty → Porch peeks in the empty-state well: eyes emerge, a settle-glance, the smile lands with the line. Plays when the state is reached, not on every visit.

condensed grammar · 1.5s · once per state change

C3 · The idle blink (rare)

After ≥4 quiet minutes, one blink. Not a loop, not an attention grab — the workshop breathing. At most once per idle stretch. Motion stays rationed: C1–C3 share one heartbeat, the top-bar mark.

same pk-blink · never while a gate card is docked

Not proposed: eye-tracking the cursor, edge-peeks over content, or any looping ambient motion — the design system rations constant motion to one heartbeat per surface, and the composer/typing dots already own the thread.

Spec sheet

what implementation adds — docs/33 lands these in the same PR

Tokens & type

  • --brand: #834a2b · --brand-ink: #fff7ee — constant in all four themes; the mark's only colors. Mirrored in client-core THEMES (CI parity).
  • --fbrand → Bricolage Grotesque 600, −0.015em, via @fontsource-variable/bricolage-grotesque (bundled, desktop + preview + web).
  • Wordmark ink is --text. Lowercase everywhere; “NeuraMesh” retired from chrome copy.

Component & motion

  • One PorchMark component (desktop) — variants: solid · small · outline(currentColor) · sheen; replaces all three EmberMark copies + the hand-inlined auth mark.
  • Peek keyframes verbatim from the handoff; blink/wake as shown. All stilled under reduced motion; launch never gates input.
  • Blink triggers: refocus (30s throttle) · idle ≥4m · lockup hover. One heartbeat: the top-bar mark only.

Rollout (after this round approves)

  • PR 1 — desktop: tokens + PorchMark + lockup + launch/wake + blinks + icons/DMG + fonts + docs/33.
  • PR 2 — web homepage: recolor + lockup + favicon/OG.
  • PR 3 — mobile: icon/splash re-export, splash colors on tokens.
  • Deploy notes: none manual — icons regenerate at build; DMG bases committed.
