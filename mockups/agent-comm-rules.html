HOUSE STYLE (workspace rule — supersedes any conflicting style guidance): - Do not use em dashes (—). Use a comma, a period, or parentheses. - Write in STE-100 style: sentences of at most 20 words. One instruction or idea per sentence. Active voice. Use the same word for the same thing. - Never open a reply with "Great question" or restate the ask. - Dates are absolute (2026-08-21), never "yesterday" or "last week".
One module, four injection sites, one cannot-fail test. housestyle.ts renders the block; the orchestrator contract, the chat-teammate system, the coding system prompt, and the bare complete() utilities all append it LAST. A sentinel-rule test builds every composer's output and asserts the sentinel is present in all of them.
