1 · The pill — .cfoot row, between project and threads

Same .cchip species as its neighbours: icon + label + caret, 11px/600, 999px radius. Label = Brain · <active pack name>; when no pack manages the workspace it reads Brain · Manual (each agent keeps its own brain). Workspace-scoped — the same pill in every room.

2 · The popup — Variant A · split paneRecommended

Anchored above the pill like .cprojpop. Left rail = every brain (curated packs, then your custom brains, then “New custom brain”); right pane = the full role→model roster of whichever brain you’re on, with the provider gate and one Apply button. Height stays fixed no matter how many brains exist — browsing rosters never scrolls the popup.

4 · Custom brain builder — modal from “＋ New custom brain” (and Edit)

Name it, pick a model per role, activate. Rows pre-fill from the active brain so you start from something sane and tweak. The provider gate is computed live from the picks: Save always works; “Save & activate” locks until every provider the picks need is connected. worker mirrors developer automatically (legacy alias). Same modal edits an existing custom brain (adds Delete).

New custom brain

A model per role, workspace-wide. Starts from your active brain — change any seat.

5 · Settings → Brains — designer seated + support row + custom cards

The existing .packcard grid gains the missing designer row, a muted support line (sales · curator — the full truth, quietly), and your custom brains as first-class cards with Edit/Delete. “New custom brain” is a dashed card at the end of the grid. Same builder modal as the popup.
