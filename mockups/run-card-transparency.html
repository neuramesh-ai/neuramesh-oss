And when it settles

The chrome question is really two questions — a run is live for minutes and a receipt forever. A settled card folds itself away, so whatever chrome you choose is what the thread carries permanently. Bare and Spine leave a quiet receipt; Whisper drops its wash on settle so it goes bare too.

Round 2 — getting at a subagent’s work

Today a leg row is not clickable at all, and the card’s one Activity button opens the orchestrator’s panel. Worse, underneath: orchSpawnFor hands every leg the parent’s log function, so all five subagents write their tool calls under rex’s agent_id and rex’s run_id — one flat, unattributed stream. You cannot tell which subagent read what, because the data was never split.

The daemon fix is small: mint a leg-scoped logger so each leg writes under its own seat and its own run id. nm.agentLogs({ runId }) already accepts a bare run id, so the read path needs nothing new. That leaves the surface question — three ways to open it, all shown on the Bare card.
