Threads mode — a per-channel toggle: focused room or live feed

The rule the design encodes: Off never moves a message — it widens the room's lens. The task thread stays the canonical record (cockpit, review gates, beats, watchdog all hang off task_id); turning threads off makes the channel feed include thread traffic inline — every agent reply tagged with its task — and lets the composer answer into a thread without leaving the room. Quick back-and-forth with rex or any agent needs no task in either mode: that's already how channel-root wakes behave. Flip the toggle back and nothing was lost, because nothing was rerouted.
