00The gap this round closes

A playbook run ends at a report today. The GEO run lands geo-report-2026-08-21.md at 74/100 with a "Recommended Next Tests" section — and then nothing consumes it. The recommendations are prose inside an artifact; acting on any of them means the human re-typing what the report already said. Round 4: the agent that finished the run reads its own report and hands over a next-steps card — individual items, each armed by one click, each click firing a REAL command from the human's client (the nmsched / task-proposal / verdict idiom: agents draft, the human's click is the consent).

Three kinds, three verbs, all existing machinery. task (a code/site change) arms via nm.createTask — the TaskProposalCard route, born to the board's normal gates. routine (recurring marketing work) arms via nm.scheduleCreate — literally the nmsched + Arm row. research (a question worth its own thread) opens a new conversation with the opener prefilled — the destination pill's stage idiom.
Enforced, not prompted: the agent writes the card through a schema-validated tool (propose_next_steps → a ```nmnext block, the draft_posts lesson: a tool inventory beats a prompt rule). The agent can never arm anything — every verb is the human's click.

03Where it comes from, where it lives

Producer: the run's finishing seam (the same one that posts the completion note) wakes ONE distill turn for the agent that owns the thread — it reads the report artifact it just delivered and calls propose_next_steps(items). The tool validates kinds and fields, refuses more than five items, dedupes against a card already posted for this report, and writes the block:

```nmnext { "report": "geo-report-2026-08-21.md", "items": [ { "kind": "task", "title": "Add JSON-LD product schema to the homepage", "why": "biggest single citability lift", "src": "Fix these first · #1", "taskKind": "chore", "description": "…" }, { "kind": "routine", "title": "Weekly GEO re-measure", "cadence": "weekly", "weekday": 1, "atTime": "08:00", "prompt": "Re-run the GEO query set; diff vs geo-report-2026-08-21." }, { "kind": "research", "title": "Why Fathom outranks us in AI answers", "opener": "Trace which sources AI answers cite for privacy-analytics queries…" } ] } ```
One derivation, every surface: the block renders as this card in the setup task's thread, in a playbook conversation, and in the subtask peek — the same postCardsFrom ruling as social drafts. One card per report (dedupe by report name); a re-run's fresh report earns a fresh card.
Arm truth is live: task rows resolve by title against open tasks, routine rows against active schedules, research rows against the thread it opened — the armed ✓ survives reloads and shows work armed from another machine (the SchedRecsCard rule).
The report stays the source of truth. The card is ≤5 items — a distillation, not a mirror. “four of nine recommendations” in the card head says honestly that the agent chose; Open report is one click away on the chip above it.
