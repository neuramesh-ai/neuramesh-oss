Design polish — five cleanups
against v0.65.0 · proposal for review

Fewer lines, one frame, and links that belong to the theme.

Five issues, each traced to a specific rule in tokens.css. Every panel below is built from the app's real tokens — switch themes in the header to check the fix holds in all four. Nothing here is implemented yet; this is the round to approve.

Issue 1 · the frame

The dock stops being its own strip

The shell paints --win; the dock paints --band — a second, darker value used by exactly one rule in the whole stylesheet (.dockbar). That seam is why the bottom reads as a separate component from the nav above it. The fix: the dock goes transparent and lets the frame show through, so nav + dock are one continuous surface.

Structure should come from spacing and material, not from drawing a line at every boundary.

Issue 3 · the thread edge

The rail and the gutter leave the task thread

The tick rail was designed for the channel feed, where a long day of history benefits from a scrub handle. A task thread is a single conversation you read top to bottom — the rail and the 9px scrollbar are chrome it can't spend, and they sit exactly where the thread meets the design panel, which is what made that edge look busy.

Issue 4 · the approve gate

The gate sits on the standard ground

The gate is painted --panel2, the warm-well token reserved for passive containers — avatar mounts, empty states, composer caps. A row holding the single most consequential button in the product is not a passive container. It moves to --panel, the close-to-white ground, and separates from the lane with a soft ledge shadow instead of a hairline.

Issue 5 · link ink

Links stop being blue

One token drives every link in the product — task refs, file refs, PR links, markdown links (--link). Cream Oak already sets it to oak. The other three themes inherit a blue that predates the revamp and belongs to no palette: #4a5ec9 on Paper, #9cb1f0 on Graphite, #a6baf2 on Soft dark. The proposal takes each theme's own brand oak and tunes it for that ground.
