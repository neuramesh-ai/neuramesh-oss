Stop 4Anatomy & motion — the spec the implementation is gated on
Numbers and rules, so the build round has no judgment calls left in it.

The nav grip

  • Hit area 10px in the nav↔sheet gutter · visible affordance only on hover (3px × 64px pill, --border2) — no resting hairline (trap 9b: the nav is naked on the frame; a standing rule would fence it).
  • Drag: transition: none (direct manipulation, tracks the pointer at 60fps) · readout bubble in --overlay shows live px · pill takes --ring.
  • Clamp 224–356px, default 266. Double-click resets (this one animates, .22s --ease).
  • Keyboard: the grip is a focusable role="separator", ← → nudge ±12px — the split-stage contract.
  • Persistence: localStorage nm:navw — machine-local like the theme, the fold, the file pane. Never synced.
  • Fold interplay: ⌘\ unchanged — folds to 0 (spine remains), grip hides with the panel; unfold restores nm:navw, not 266. Both faces of the column share the width by construction (same box).

The reveal (filter + project menus)

  • The chip-pop recipe: enter --dur-enter (.22s) with a 6px rise; rows stagger 24ms apart, capped at 8; exit --dur-exit (.13s). Non-blocking — the page stays interactive.
  • Scrim click and Esc close; Esc unwinds exactly one layer.
  • Menus portal to <body> — Home's column scrolls, and a scrolling container cannot host a dropdown (docs/33 §8, three-time offender).
  • Filter pill states: rest = ghost (border, muted) · open = --sel-bg · applied = --accent-soft wash + label swap (#build · flowe-ai) + ×. Warm-as-selection is the idiom; the pill never changes hue for anything else.
  • Set filters persist per machine (nm:homescope) so Home reopens as you left it; the pills make the carried state visible, which is what makes persistence safe.

The frame top & the retired dock (round 3)

  • The utilities live on the frame top, right end, after the ⌘K search pill: terminal · browser · console · activity · the Synced pill — the bottom strip's cluster verbatim, one row that exists on every page. The dock's ⌘ tile folds into the ⌘K pill: one palette door, not two.
  • The bottom dock strip retires: the frame's .shell padding gives its 38px back to the sheet. The frame top's height is unchanged — its right end had the room.
  • Everything there is -webkit-app-region: no-drag inside the drag bar, exactly as the ⌘K pill already is. Under ~880px the icon cluster folds into a ⋯ overflow — never a second row.
  • Synced keeps its pill anatomy (dot + word); the dot goes --warn-toned while the upload queue holds writes, exactly as the dock's did.
  • The main section's right rail is ONE container (the collision fix): crew clusters · views burger · split · file-pane toggle in one flex row, fixed order, uniform 30px targets, one positioning context — two absolutely-positioned groups sharing a corner is how the Files toggle ended up under the burger. Tooltips near the right edge mirror their offset (docs/33 §8) so a label can never cover a neighbour.

Home & the stage

  • Home's column stays on --col (860px); one scroller for the whole page; sections keep the serif .hsect voice; day heads keep the mono voice. 60fps list: rings are conic-gradients, one row component.
  • The greeting is two lines — mono date eyebrow + the serif hello. The report sentence is deleted, not conditional: the queue cards below carry the same facts with their buttons on (round 2).
  • Home renders no search field (round 3): ⌘K stays the global door; the Recent heading's icon (and ⌘Y, unchanged) opens the history overlay, which keeps the product's one history-search field — the docs/32 §12 ruling stands.
  • ⌘N opens the stage. Boot lands on Home.
  • The stage centers on a 600px column, optically ~42% down the sheet; greeting 27px --fdisp, the project name --fital italic in --link with a 45%-alpha dotted underline.
  • On send the composer docks bottom and the thread mounts above — one animated number (the column's top padding), .22s, non-blocking; reduced motion cuts straight to the docked layout.
  • Needs-you cards keep every button they have today — the queue's one-click contract (docs/32 §10) survives the move intact.
