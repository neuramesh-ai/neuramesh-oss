Library → Workspace Files

Three directions for the files destination, plus the fix for the two live defects: brand docs that exist but never reach the Library, and a thinking chip that says what the ghost above it already said.

A · The Shelfrecommended

Root is every project, always — no active-project scoping, which is what makes files feel missing today. A folder is the project itself: its own mark, its rooms, and the crew that can read it. One level down is the file list. Two levels, never three.

  • The folder is the project — it wears the project's own auto-detected logo, not a generic blue icon. Achromatic in Graphite; the mark is the only warm object.
  • The access row puts the ACL on the surface: those avatars are the agents registered to that project's rooms. Today that rule is real but invisible, so "can rex read this?" is unanswerable from the UI.
  • Folder tab + peeking sheet edges are pure CSS on --card — a folder silhouette that costs no colour and survives both themes.
A · inside a projectone level down

Breadcrumb back to root, kind chips instead of nested folders (the folderchips idiom already shipped in the marketing library), and the file table the reference screenshots ask for — typed, sized, dated, and tagged with the room that owns it.

  • The ★ stops being a gate and becomes a marker. Today the Library only shows promoted = 1, which is why seven brand docs are invisible. Here every file shows; the star means "the human curated this onto the shelf", and a Shelf chip filters to just those.
  • Room, not project, is the column — because the room is the ACL. A file's project is derived from its room, exactly like a task's.
  • Row click opens the same reader overlay that already renders docs, diffs, mockups and images (previewType, docs/30). No new viewer.
B · One folded tableno navigation

Same data, zero clicks to reach anything: one table, grouped by project with collapsible headers. Better when the workspace holds tens of files rather than hundreds — and search is instant because you are already looking at everything.
