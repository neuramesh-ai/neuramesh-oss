# NeuraMesh. Social Media Strategy

## Platform Priority
**Primary: X/Twitter** → this is where developers argue about AI agents in real time, and the "AI agent memory / compounding context" narrative is currently unowned there (per market-research.md). The Week 1 → Week 4 before/after arc is native to the format and built to be quote-tweeted. **Secondaries:** Reddit r/AI_Agents (404K+ subs, value-first, never pitch) for reach into an engaged agent audience, and LinkedIn for founder-voice posts riding the "agentic AI chaos" sentiment.

## Core Narrative Pillars
1. **Agents that remember** → "Subagents forget everything. Your team shouldn't." Every task with a stateless agent starts from zero; here, corrections become lessons that carry forward.
2. **A named team, not a new stranger every task** → Scout 🐝, Iris 🦋, Atlas 🦉, Patch 🦊 are persistent teammates with roles, not disposable context-free subagents.
3. **Week 4 beats Week 1** → the compounding-context story. The same team gets better because your corrections stick.
4. **Your keys, your machine** → BYOS with no token markup, and code never leaves your machine. For cost-sensitive and privacy-conscious devs alike.
5. **You define and accept; the agents run the middle** → Define → Design gate → Plan & Build → Review → Accept. The human owns both ends and keeps control.

## Content Formats That Work
- **Before/after threads:** the same review comment on Week 1 vs Week 4 → the shareable proof of compounding memory.
- **Agent-personality posts:** short, dry bits voiced as Scout/Iris/Atlas/Patch doing their jobs (or catching a bug).
- **Build-in-public updates:** "built with itself" progress, including the iPhone companion app in App Store review.
- **Pain-first one-liners:** name the universal frustration, let devs self-identify, land on the product truth.
- **Comparison cards:** stateless-per-task vs persistent-team → framed as product truth, not hype.

## Posting Cadence (Starter)
- **X/Twitter:** 1 main post/day Mon–Fri (5/week); anchor one before/after thread each week (Tue or Thu).
- **Reddit:** 1–2 genuinely useful comments/week in r/AI_Agents → answer questions, never promote.
- **LinkedIn:** 1 founder-voice post/week reacting to the "agentic AI chaos" conversation.

## Tone Rules
- Developer-native. Never marketing-y. Lead with the pain, not the product.
- Short sentences. Dry wit ("A new stranger every task"). Anti-hype.
- Use "→" as punctuation to match site voice.
- Give the agents personality, but keep the substance on compounding memory and control. Never invent stats → write what's true or say nothing.
