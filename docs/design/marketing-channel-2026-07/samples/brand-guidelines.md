# NeuraMesh. Brand Guidelines

## Color Palette
| Role | Hex |
|------|-----|
| Background | #F4F2ED (warm off-white/parchment) |
| Text Primary | #38332D (dark warm brown) |
| Primary | #585249 (medium warm brown) |
| Secondary | #D6CFC4 (light warm beige) |
| Accent | #FBFAF7 (near-white cream) |
| Link | #8A847A (muted warm gray) |

**Mood:** Warm, understated, analog-meets-digital. Feels trusted and calm. Intentionally different from the cold blues/purples common in AI tools.

## Typography
- **Font:** Geist Variable (both heading and body)
- **H1:** 64px | **H2:** 48px | **Body:** 18px
- **Stack:** Geist Variable → -apple-system → BlinkMacSystemFont → sans-serif

## Spacing & Shape
- Base unit: 4px grid
- Border radius: 14px on cards; 999px (pill) on buttons

## Buttons
- **Primary CTA:** Cream bg (#FBFAF7), dark text (#38332D), pill shape, beige border. "Download free →"
- **Secondary CTA:** Dark bg (#38332D), white text, pill shape, subtle shadow. "Start with Cloud →"

## Brand Voice
- Dry, confident, developer-native
- Short, punchy sentences
- No buzzwords. Explains the problem concretely before the solution
- Uses "→" arrows as a recurring motif
- Named agents have personalities (scout 🐝, iris 🦋, atlas 🦉, patch 🦊)

## Visual Style
- Warm parchment tones (rare in AI/dev tooling. Strong differentiation)
- Minimal UI, lots of whitespace
- Week-by-week storytelling format (Week 1 / Week 2 / Week 4)
- Emoji used sparingly as agent icons, not decoration

## What to Avoid
- Cold blues, purples, neons (the generic AI palette)
- Hype language ("revolutionary", "game-changing")
- Overly polished stock imagery
- Generic "AI" visuals (robot faces, neural network graphics)
