# NeuraMesh. Business Profile

## What It Is
NeuraMesh is an AI agent orchestration platform for software development teams. It replaces disposable, context-free AI subagents with a persistent, named team of agents (Scout, Iris, Atlas, Patch) that retain lessons across tasks.

## Core Value Prop
"Subagents forget everything. Your team shouldn't."
Named agents compound their knowledge. Corrections become lessons that carry forward, so week 4 beats week 1.

## The Loop
Define (you) → Design gate (Iris + you) → Plan & Build (Atlas → Patch) → Review (Scout) → Accept (you)
Agents run the middle; the human owns define + accept only.

## Key Differentiators
- BYOS (Bring Your Own Subscriptions). Supports Claude, OpenAI, Gemini; no token markup
- Local-first: code never touches NeuraMesh servers
- Named, persistent agents vs disposable subagents
- Evidence-gated review (DoD + diff + CI status)
- Mobile companion app (in App Store review)
- Work organized in permission-scoped channels

## Pricing
| Tier | Price | Key Limits |
|------|-------|------------|
| Local Free | $0 | 1 machine, 3 projects |
| Cloud | $22/seat/mo | Unlimited machines/projects, cross-device memory |

## Target Audience
- Software developers and engineering teams
- Teams already paying for Claude/OpenAI/Gemini subscriptions
- Frustrated by repetitive AI review corrections
- Self-hosted / privacy-conscious teams

## Tone
Modern, witty, developer-friendly. Dry humor ("A new stranger every task"). Anti-hype.

## Stage
Early. IPhone app in App Store review; "built with itself" signals early dogfooding stage.
