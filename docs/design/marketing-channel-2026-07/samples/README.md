# Brand-doc samples — the shape contract

George's Helena-generated docs for NeuraMesh itself (from `~/Desktop/neuramesh`, 2026-07-20),
committed verbatim as the **shape contract** for the marketing bootstrap's four deliverables.

The daemon's `runMarketingBootstrap` (apps/desktop/src/main/agents.ts) carries each doc's
section outline distilled from these files — title format `# <Product>. <Doc name>`, section
order, tables where the sample uses tables (pricing, competitors, palette), numbered
bold-labeled pillars/segments, and the honest one-line `Stage`. If the sample shape evolves,
update BOTH the file here and the outline in the daemon.

| Sample | Drives |
|--------|--------|
| business-profile.md | what it is · value prop · loop · differentiators · pricing table · audience · tone · stage |
| brand-guidelines.md | palette table + mood · typography · spacing/shape · buttons · voice · visual style · avoid |
| market-research.md | competitor table · strategic wedge · market signals · audience segments · opportunity gaps |
| social-strategy.md | platform priority · narrative pillars · formats · cadence · tone rules · hashtags · quick-win drafts |

Grounding stays the bootstrap's rule, not the sample's: every claim from the real site or
public sources, `unknown` where the source is silent.
