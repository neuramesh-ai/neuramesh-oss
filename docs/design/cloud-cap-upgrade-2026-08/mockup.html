Design round for the moment a free workspace's cloud machine will not start because the day's machine hours are spent. Tokens are copied verbatim from tokens.css; every idiom below is an existing one (docs/33 §8) except the compute pill and the reason line, which are called out. Flip the theme with the button — both must hold (§9.9).

A · new idiom
The compute pill, beside the sync mark

Machine state has two axes today — intent (desired_replicas) and liveness (last_seen_at) — and the UI renders only liveness, so one word "offline" covers five situations. The pill renders a single derived state instead. It is quiet when nothing is wrong: a bare dot for online and asleep, and only the states that want you to act earn a word and a wash.

B · the blocking moment · existing idiom (docs/25 gate card)
In the thread, where the unanswered message is

This is the case George hit: a message sent, no reply, no explanation. The cap notice belongs in the conversation, docked above the composer, because that is where the person is waiting — not only in a settings page they have no reason to open. docs/25 allows exactly one contextual gate card there, and a conversation that cannot proceed is exactly a gate.

The line that matters most is the last one: the message is not lost. The host already sweeps messages it slept through (chatsweep.ts), so "we will answer it when the machine wakes" is a promise the system actually keeps.

D · existing surface (sheets.tsx UpgradeModal) + one new element
The upgrade decision, entered with the cap as its reason
