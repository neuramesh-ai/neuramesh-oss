# Duration formatter

Implement `formatDuration(seconds)` in `src/duration.mjs`. Accept non-negative safe integers, returning `H:MM:SS` with unbounded hours and two-digit minutes/seconds. Throw TypeError for non-numbers and RangeError for negative, fractional, infinite, NaN or unsafe values. Do not coerce strings. Preserve the named export. Add boundary tests and run `npm test`.

No dependencies or network access are needed. Change only src/, test/ and this README. Do not commit or push.
